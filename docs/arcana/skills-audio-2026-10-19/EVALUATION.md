## Qué se aplicó realmente

- Asset Audit: inventario de los16WAV activos, consumidores, bytes/formato/frecuencia/duración/hash frente a los manifests originales y mezcla conservadora. No se aplican reglas Godot de POT, nombres con underscores u OGG sobre Web Audio/Pixi. Auditoría de arte deA87 reutilizada como antecedente, no una nueva revisión visual exhaustiva.
- Audio Design: mantener buses existentes, consentimiento y headroom; corregir independencia de ambiente frente a efectos lentos. No añadir stems, pitch aleatorio o middleware.
- Performance Optimization: medir concurrencia mediante dependencias retenidas, reproducir antes de tocar, limitar carga+decode y conservar coste de tener todos los efectos listos. No confundir concurrencia con FPS o GPU.

Se descartó instalar todo el estudio, duplicar las skills existentes o añadir generación de vídeo/3D. No se ejecutó ningún instalador upstream, npx remoto, hook, daemon, API de generación, proceso gráfico o revisión con subagentes. Se usó el instalador propio deCodex con destino explícito local y revisión fijada. Una skill instalada no acredita mejora: las pruebas del juego y la CI se registran por separado.
