## Recomendación

Conservar **orientación inicial → intención de compañía → hechos del combate** (PM02/03/06). El siguiente bloque de ampliación debe conectar **Cromodex con un objetivo → varita con un portador → gragea con una decisión de riesgo** (PM05/18/19). El valor esperado es poder usar mejor lo obtenido; no es retención o diversión demostrada.

Suben de prioridad el Cromodex orientado a una meta y la investigación de excedentes/obtención. Después propondría capítulos finitos de descubrimiento y uso. Como tienda nueva, probaría primero una **librería**, reutilizando esos objetivos, antes de producir una fachada. Botica, ranas temáticas y bóveda a elección requieren decisiones económicas específicas; no se implementan por documentarlas.

## Límites de decisión

El valor de negocio en esta fase es reducir confusión, proteger confianza y facilitar experimentación voluntaria con coste de producción sostenible. No hay tráfico, ingresos, LTV, CAC o retención reales analizados. No se proponen rachas, XP, monedas, mejoras infinitas, monetización o trading como añadidos implícitos.

Se conservan Teatro de alquimia, Diagon Alley principal/ARCANA intercambiable, ES/EN desde Ajustes, accesibilidad, vínculo único, encantado cosmético, operaciones recuperables y BattleLog confirmado. No se ejecuta navegador local ni se presenta documentación como validación humana. Aprobar e implementar un futuro incremento requiere seleccionar su alcance y resolver las reglas materiales pendientes.
